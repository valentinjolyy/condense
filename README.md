# Le Condensé

Revue de presse personnelle (Le Monde, Le Figaro, franceinfo), rédigée chaque heure par Claude à partir des articles complets.

- Application : https://valentinjolyy.github.io/condense/ (iPhone : Safari > Partager > Sur l'écran d'accueil)
- Les données (`data/bundle.json`) sont chiffrées en AES-256-GCM ; la phrase secrète est demandée à la première ouverture.
- Mises à jour : tâche planifiée Claude, toutes les heures, sur le Mac de Valentin. L'app vérifie les nouveautés chaque minute.
